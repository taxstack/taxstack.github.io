# taxstack.github.io

The TaxStack project website — served at **https://taxstack.github.io**

Plain `index.html`, no build step. Content links into the main project repo at [github.com/taxstack/taxstack](https://github.com/taxstack/taxstack).

This repo exists because GitHub only maps `<username>.github.io` to the root domain — the project repo (`taxstack/taxstack`) can't serve it.
